# Assessor Portal: Change Log

One line for each change people would notice, newest first. Add a line here with every change to the portal.

## November 2026

- **Nov 25:** The browser's Back button works: it goes to the last page you were on in the menu and closes an open engagement first; it never undoes a change (CN-033).
- **Nov 25:** Browser tab icon now matches mismo.org (the shared MISMO icon, on every page).
- **Nov 22:** Changes go live only after every check passes ("Checks and Publish"); a change that fails a check is not published.
- **Nov 22:** Waiting on the company's evidence counts as With You (the firm follows up for it). Once only the Mark License Agreement is left, the engagement leaves the board.
- **Nov 22:** Version stamp at the foot of Help (fingerprint and publish time); the page offers a reload when a newer copy is published. System Health page for MISMO administrators: the relay, each firm's engagements from the CMS, steps not yet picked up, latest uploads and weekly times, and script problems.
- **Nov 21:** Automatic checks on every change (scripts parse, nothing private in the page, a click-through with a made-up firm). Guide and change log added.
- **Nov 21:** Documents open in a tab only as a PDF or a plain picture, typed from their own file extension; anything else downloads.
- **Nov 16:** The remediation step is called "All Findings Remediated", with a pointer to it on Overview and Documents.
- **Nov 16:** Uploads are recorded where assessors can save (they were reaching SharePoint but not showing in the list).
- **Nov 10:** Large files, such as demonstration recordings, upload in parts straight to the library (up to 15 GB).
- **Nov 9:** Put on Hold and Ready to Resume on each engagement.
- **Nov 6:** File names with apostrophes no longer break document links.
- **Nov 5:** Saving your weekly times merges with the newest copy instead of overwriting it.
- **Nov 1:** Stress test fixes: phone layout for next moves, schedule and help; a refused save says so in plain words.
- **Nov 1:** Earlier Certifications: every cycle, initial first, each one opens.
- **Nov 1:** Certification Script tab: read the script on screen, section by section, with the company's answers and a search. The Excel copy is still offered.
